# Photo openers

Drop a photograph here named after the post id — `M2.jpg`, `M7.png`, `M12.webp` — and `node social/render.mjs <id>`
puts it behind the first card of that post (the one that shows on the Instagram grid). The rest of a carousel stays
on the abstract glass ground. No file, no photo: the post renders exactly as before.

Rules that apply to the photo itself (CLAUDE.md, BRAND.md): no NeroPay-branded props, no competitor branding, no
legible real data (statements, screens, receipts), no identifiable real merchant without consent, deep focus and no
bokeh. Generated images: keep the Higgsfield prompt next to the file as `<id>.prompt.txt`.
