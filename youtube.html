Why the still comes firstVideo models mangle text and numbers; image models render them reliably. Generate the graphic as a still, hand it to the video model as the end frame, and the final frame is pixel-correct even if the middle wobbles. Never let a video model invent a figure — every number in these overlays is a substantiated claim.
Or skip the image model entirelyEvery overlay still, card, plate and question card is drawn on this page as an exact SVG. Download it as a transparent PNG and drop it on the timeline, or use it as the END frame for the animation step. Same figures, same layout, no spelling roulette.
Compositing — read before you generateHiggsfield does not output an alpha channel, so every generated overlay is built on pure black. Composite with a Screen or Add blend mode and the black drops out. If the black comes back lit, greyish or gradient-y, regenerate — a muddy black keys badly. The PNGs from this page don't have that problem: the transparent version needs no keying.
The call layoutBehind the Counter is assembled in post: the owner's bite full-frame, the host listening loop scaled into the box top right (the Call layout asset marks the box and its NeroPay plate), the owner's name plate bottom left, and the disclosure over the first three seconds. Cut host question → title → question card → bites → host question → bites → host close → end card.
