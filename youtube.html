01

How to use this

Three kinds of generation. Every one starts with a global prompt, then the piece that's specific to the shot.

TypeToolWhat you attachWhat you paste
Presenter shotVideo genThe presenter starting frame from the prompt kit (not in this repo)Copy global + shot — the presenter global and the shot prompt, together
Overlay stillImage gen — Nano Banana Pro, 2KNothing. Text to image. This becomes the END frameCopy still prompt
Overlay animationVideo genA plain black frame as START, the still as ENDCopy global + animation — the overlay global and the animation prompt
Why the still comes firstVideo models mangle text and numbers; image models render them reliably. Generate the graphic as a still, hand it to the video model as the end frame, and the final frame is pixel-correct even if the middle wobbles. Never let a video model invent a figure — every number in these overlays is a substantiated claim.
Or skip the image model entirelyEvery overlay still is also drawn on this page as an exact SVG, under its prompt and in the Assets tab. Download it as a transparent PNG and drop it straight on the timeline, or use it as the END frame for the animation step. Same figures, same layout, no spelling roulette.
Compositing — read before you generateHiggsfield does not output an alpha channel, so every generated overlay is built on pure black. Composite with a Screen or Add blend mode and the black drops out. If the black comes back lit, greyish or gradient-y, regenerate — a muddy black keys badly and you will see a grey box. The PNGs from this page don't have that problem: the transparent version needs no keying.
The specimen statementThe redacted statement footage slots in alongside OV-2 on B1, which is the itemised table. Both specimen statements are in the Assets tab at 1920×1080. Shoot or screen-record at the same aspect and cut between them and the overlay rather than stacking them.
