03

How this stays true

The register is only worth opening if it is right. Three rules.

A session writes the row when it delivers. Anything rendered gets a row here in the same commit that renders it — not a Drive README, not a commit message, not a line in chat. The row carries the crop, the link, the md5 and the build folder.

Any state may be set by a session, including approved — but only when Faisal says so in chat, and it must carry who and when. That is Faisal's ruling of 22 Sep 2026. The by field is what keeps it honest: an approval nobody can attribute is the thing that lost track in the first place. Never infer approved from a render, a delivery, or a README that calls itself final — three of the videos below do exactly that and none of them was ever confirmed.

backup: false is a live problem, not a note. It means the only copy is a CDN link. It flips to true when the MP4 is sitting in its Drive folder, and only Faisal can do that — the connector will not carry a file that size.
